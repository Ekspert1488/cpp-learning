## Скрипты в хронологическом порядке:
1. renum_ss.py - также чинит одноцепочечные аптамеры,а точнее их pdb файлы
2. repair_ss.py -  аналогично чинит одноцепочечные аптамеры, но делает это конвеером.
3. run_apt3d_chunk.py - запускает создание pdb файлов аптамеров из файла apt_tasks.csv - указано буквенное название аптамера и его вторичная структура. На выходе получаем файл apt3d_results.csv. С данными столбацми:
    **name** - Номер аптамера(название файла);
    **ok** -  True or False в зависимости от успешности создания 3д модели;
    **L** -  длина аптамера;
    **atoms** - количество атомов в аптамере;
    **charge** - посчитанный заряд аптамера;
    **expected** - ожидаемыйй заряд ;
    **ret**  - код возврата внешней программы;
    **reason**  - причина неудачи, если прошло успешно, то поле пусто;
    **seconds** - время, прошедшее с запуска;
4. dock_apt.py -  запуск "чернового докинга" для аптамеров. На выходе получаем файл: scores_apt.csv с такими столбцами: 
    **name** - название файла аптомера (порядковый номер);
    **kind**  - тут один тип - ss;
    **L** - длина аптамера;
    **src** - Инструмент, с помощью которого происходила сборка
    **score_extra** -   лучший score докинга для тех положений, чье минимальное расстояние до внеклеточной части меньше 7 ангстрем(чем меньше тем больше вероятность связывания);
    **dist_extra** -  минимальное расстояние между атомами  внеклеточной части рецептора и фрагмента в ангстремах;
    **n_near_extra** - количество  положений из **n_max** = 100, которые были "связаны"(минимальное расстояние не более 7 ангстрем) с внеклеточной частью рецептора;
    **score_epi** - лучший score докинга для тех положений, чье минимальное расстояние до эпитопа меньше 7 ангстрем.;
    **dist_epi** -  минимальное расстояние между атомами  эпитопа рецептора и фрагмента в ангстремах;
    **n_near_epi** - количество  положений из **n_max** = 100, которые были "связаны"(минимальное расстояние не более 7 ангстрем) с эпитопом рецептора;
5. rank_apt.py - запускает сортировку по скору - дистанции и количеству успешных поз из 100. Выход два файла: ranked_epi.csv и top500.csv
    Столбцы первого файла: 
        **rank** -место в рейтинге по скору епитопа;
        **name** - название файла(порядковый номер аптамера);
        **kind**  - тут один тип - ss;
        **L** - длина аптамера;
        **src** - Инструмент, с помощью которого происходила сборка
        **score_extra** -   лучший score докинга для тех положений, чье минимальное расстояние до внеклеточной части меньше 7 ангстрем(чем меньше тем больше вероятность связывания);
        **dist_extra** -  минимальное расстояние между атомами  внеклеточной части рецептора и фрагмента в ангстремах;
        **n_near_extra** - количество  положений из **n_max** = 100, которые были "связаны"(минимальное расстояние не более 7 ангстрем) с внеклеточной частью рецептора;
        **score_epi** - лучший score докинга для тех положений, чье минимальное расстояние до эпитопа меньше 7 ангстрем.;
        **dist_epi** -  минимальное расстояние между атомами  эпитопа рецептора и фрагмента в ангстремах;
        **n_near_epi** - количество  положений из **n_max** = 100, которые были "связаны"(минимальное расстояние не более 7 ангстрем) с эпитопом рецептора;
    Cтолбцы второго файла такие же (просто файл с топ 500 аптамеров);
6. diag_shape -  считает такие параметры как: медианное, максимальное и минимальное значение расстояния между 5' и 3',радиуса инерции, параметра растянутости e2e/L. Никак не влияло на отбор, но позволяет удостовериться, что 3д структуры получаются логичными.
